1. PURPOSE OF APPLICATION
Raft Multiplayer Launcher is designed to automate save-game synchronization and facilitate turn-based / co-op multiplayer gameplay in Raft using Git & GitHub.

2. SAVE-GAME SYNCHRONIZATION

This application will read and update your Raft save games based on the specified shared world repository.

The application automatically creates a local save-game backup before performing any updates to keep your data safe.

3. PRIVACY & SECURITY
